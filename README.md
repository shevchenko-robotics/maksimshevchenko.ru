# maksimshevchenko.ru

Личный сайт Максима Шевченко.

## Устройство

- `src/page.html` — исходник страницы на двух языках. Элементы для одного языка помечены атрибутами `data-ru` или `data-en`.
- `tools/build.py` собирает из исходника две страницы: `index.html` (русская, `/`) и `en/index.html` (английская, `/en/`). Для каждой убирается текст другого языка, проставляются SEO-теги, `hreflang` и разметка schema.org.
- Сборка: `python3 tools/build.py` (нужен пакет `beautifulsoup4`). Собранные страницы коммитятся вместе с исходником.
- `src/cv.html` — резюме на двух языках; `python3 tools/cv.py` (нужен `playwright`) печатает его в `cv/shevchenko-cv-ru.pdf` и `cv/shevchenko-cv-en.pdf`.
- Адрес почты на страницах хранится в перевёрнутом виде и собирается скриптом, чтобы его не находили спам-боты.
- Тема оформления по умолчанию следует за настройкой устройства (`prefers-color-scheme`). Кнопка в шапке переключает по кругу «как в системе → светлая → тёмная»; выбор хранится в `localStorage` под ключом `theme` и применяется скриптом в `<head>` до отрисовки, без вспышки другой темы. `404.html` учитывает этот выбор.
- `data/records.json` — патенты, публикации и упоминания. Из него собираются разделы сайта и список в резюме: после правки запустите `python3 tools/build.py` и `python3 tools/cv.py`.
- `.github/workflows/links.yml` — раз в месяц проверяет все внешние ссылки на сайте и заводит задачу (issue), если какие-то перестали открываться.
- `.github/social-preview.png` — картинка превью репозитория на GitHub (1280×640, важное — в пределах 80 px от краёв), исходник — `tools/social-preview.html`; загружается вручную в Settings → Social preview (у каждого репозитория отдельно). Картинка для соцсетей у самого сайта — `og.jpg` (1200×630).
- `robots.txt`, `sitemap.xml`, `404.html` — служебные файлы GitHub Pages. `CNAME` здесь справочный: домен привязывается в настройках Pages публичного репозитория, Action этот файл не копирует.

Шрифт Onest распространяется по лицензии SIL Open Font License (`fonts/OFL.txt`).

## Публикация

Этот репозиторий приватный: в нём исходники и инструменты. Сайт раздаётся из отдельного публичного репозитория [`shevchenko-robotics/shevchenko-robotics.github.io`](https://github.com/shevchenko-robotics/shevchenko-robotics.github.io), в котором лежат только собранные файлы.

- После каждого слияния в `main` workflow `.github/workflows/publish.yml` копирует файлы из списка `.github/publish-files.txt` в публичный репозиторий и делает там коммит с нейтральным сообщением («Обновление сайта» и дата). Если публикуемые файлы не изменились (например, правился только README), коммита нет.
- Публикуется только то, что перечислено в `.github/publish-files.txt`. Новый файл, который должен быть на сайте, добавляется в этот список в том же PR.
- Доступ к публичному репозиторию — через deploy key с правом записи только на него; приватная часть лежит в секрете `PUBLIC_SITE_DEPLOY_KEY` этого репозитория.
- В публичный репозиторий вручную не пушить: следующая публикация перезапишет его содержимое. Запустить публикацию вручную можно во вкладке Actions («Публикация сайта» → Run workflow).
